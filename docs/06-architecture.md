# Архитектура транслятора Z

## 1. Общие сведения

Транслятор языка Z обозначается `zc`.

Первая реализация выполнена на языке Go. Средства реализации не входят в синтаксис и семантику языка Z. Исходный текст программ записывается на языке Z с собственными ключевыми словами (`fun`, `entry`, `out`, `loop`, типы `num` / `real` / `text` / `flag`).

Целевые платформы транслятора:

- Linux, архитектура amd64;
- Windows, архитектура amd64.

## 2. Схема обработки исходного текста

```text
Исходный файл (.z)
        │
        ▼
Лексический анализ
        │
        ▼
Синтаксический анализ  →  AST
        │
        ▼
Семантический анализ
        │
        ├──────────────► исполнение (режим run)
        │
        └──────────────► генерация кода и получение
                         исполняемого файла (режим build)
```

## 3. Модули реализации

```text
cmd/zc               интерфейс командной строки
internal/token       классы лексем
internal/lexer       лексический анализатор
internal/ast         абстрактное синтаксическое дерево
internal/parser      синтаксический анализатор
internal/sema        семантический анализ
internal/interp      исполнение программы
internal/codegen     генеративный блок
internal/compiler    организация этапов трансляции
```

## 4. Командный интерфейс

```text
zc version
zc run <файл.z>
zc build <файл.z> [-o <имя>]
```

| Команда | Назначение |
| ------- | ---------- |
| `version` | вывод версии транслятора |
| `run` | трансляция и исполнение программы |
| `build` | трансляция и формирование исполняемого файла |

## 5. Сборка транслятора

Сборка `zc` из исходного кода реализации:

```text
./scripts/build-release.sh
```

Результат:

```text
bin/zc-<версия>-linux-amd64
bin/zc-<версия>-windows-amd64.exe
```

## 6. Взаимодействие блоков

1. Лексический анализатор преобразует текст в поток лексем.
2. Синтаксический анализатор строит AST по РБНФ.
3. Семантический анализатор проверяет типы, области видимости и контекстные ограничения.
4. Генеративный блок либо исполняет программу, либо формирует целевой код исполняемого файла.

При обнаружении лексической, синтаксической или семантической ошибки трансляция прекращается.
