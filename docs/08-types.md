# Система типов языка Z

## 1. Базовые типы

| Тип | Назначение |
| --- | ---------- |
| `num` | знаковое 32-битное целое |
| `real` | вещественное число двойной точности |
| `text` | строка UTF-8 |
| `flag` | логическое значение `yes` / `no` |

## 2. Массивы

Тип массива: `[]T`, где `T` — простой тип.

- все элементы одного типа `T`;
- индекс имеет тип `num`;
- индексация с нуля;
- присваивание массива копирует ссылку.

## 3. Правила совместимости

1. Неявные преобразования отсутствуют.
2. `num` и `real` не смешиваются в одной арифметической операции.
3. Для `text` допустима только конкатенация `+`.
4. Условие `if` / `loop` имеет тип `flag`.
5. Тип присваивания совпадает с типом переменной.
6. Тип аргумента совпадает с типом параметра.
7. Тип `return` совпадает с объявленным результатом функции.

## 4. Объявления

```text
имя: тип = выражение
имя: тип
имя := выражение
```

`:=` выводит тип из инициализатора и допустим только при новом объявлении.

## 5. Связь с выражениями

Грамматика выражений разделена по типам результата. Это исключает формы вроде `- "text"` или `"a" * 2` на уровне структуры языка; семантический анализ дополнительно проверяет типы идентификаторов и вызовов.
