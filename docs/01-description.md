# Описание языка Z

Z — учебный императивный язык программирования со статической строгой типизацией.

Язык предназначен для описания программ с явными типами, управляющими конструкциями, функциями, массивами и операциями ввода-вывода. Неявные преобразования типов отсутствуют.

## Основные свойства

1. Статическая строгая типизация.
2. Объявление `имя: тип = значение` или вывод типа `имя := значение`.
3. Типы: `num`, `real`, `text`, `flag`.
4. Массивы вида `[]T`.
5. Управляющие конструкции: `if` / `else`, `loop`, `for`.
6. Объявление функций: `fun`.
7. Точка входа: `fun entry()`.
8. Ввод `in<тип>()`, вывод `out(...)`.
9. Однострочные комментарии `//`.

## Пример программы

```z
fun add(a: num, b: num): num {
    return a + b
}

fun entry() {
    x: num = 10
    y := 20
    out(add(x, y))

    name := "Z"
    out(name + " language")

    i := 0
    loop i < 3 {
        out(i)
        i = i + 1
    }

    for k from 1 to 3 {
        out(k)
    }
}
```

## Особенности

- Нет неявных преобразований между `num`, `real`, `text` и `flag`.
- Условие `if` и `loop` имеет тип `flag`.
- Для `text` допустима только конкатенация `+`.
- Цикл `for` имеет форму `from … to …`.
- Ввод типизирован: `in<тип>()`.

## Транслятор

Транслятор языка обозначается `zc`. Первая реализация выполнена на языке Go.

Режимы:

- `zc run` — трансляция и исполнение;
- `zc build` — трансляция и получение исполняемого файла.

Сборки размещаются в каталоге `bin/`.
