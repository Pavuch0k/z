# Семантическая спецификация языка Z

## 1. Сводная таблица операций

| Операция | Допустимые типы | Результат |
| -------- | --------------- | --------- |
| `-` (унарный) | `num` | `num` |
| `-` (унарный) | `real` | `real` |
| `!` | `flag` | `flag` |
| `+ - * /` | `num`, `num` | `num` |
| `%` | `num`, `num` | `num` |
| `+ - * /` | `real`, `real` | `real` |
| `+` | `text`, `text` | `text` |
| `< <= > >=` | `num`, `num` | `flag` |
| `< <= > >=` | `real`, `real` | `flag` |
| `== !=` | одинаковые простые типы | `flag` |
| `&&` | `flag`, `flag` | `flag` |
| `\|\|` | `flag`, `flag` | `flag` |

Неявные преобразования типов отсутствуют.

Для типа `text` единственная арифметически выглядящая операция — конкатенация `+`. Операции `-`, `*`, `/`, `%` и унарный `-` к строкам не применяются.

### Контекстные правила выражений

1. `ЦелочисленныйОперанд` ссылается только на объект типа `num`.
2. `ВещественныйОперанд` ссылается только на объект типа `real`.
3. `СтроковыйОперанд` ссылается только на объект типа `text`.
4. `ЛогическийОперанд` ссылается только на объект типа `flag` либо представляет результат допустимого сравнения.
5. Вызов функции допускается в выражении данного типа только при совпадении возвращаемого типа функции с этим типом.
6. Доступ к элементу массива допускается только при совпадении типа элемента с типом выражения.
7. Смешивание `num` и `real` в одном арифметическом выражении запрещено.
8. Операторы `*`, `/`, `%`, `-` не применяются к `text`.
9. Операторы `&&`, `||`, `!` применяются только к `flag`.
10. Операторы `<`, `<=`, `>`, `>=` применяются только к значениям одного числового типа.
11. Операторы `==` и `!=` применяются только к значениям одного простого типа.

## 2. Переменные, массивы и области видимости

1. Переменная объявляется до использования. Тип фиксируется при объявлении и не изменяется.
2. Повторное объявление имени в одной области видимости запрещено.
3. Тип инициализатора и правой части присваивания должен совпадать с типом переменной.

Корректно:

```z
age: num = 5
age = 10
```

Ошибка:

```z
age: num = 5
age = "Storm"
```

4. Форма `имя := выражение` объявляет переменную и выводит тип из выражения. Повторное использование `:=` для уже объявленного имени запрещено.
5. Массив `[]T` содержит только элементы типа `T`. Все элементы литерала массива имеют одинаковый тип.

Корректно:

```z
ages: []num = [2, 4, 7]
```

Ошибка:

```z
ages: []num = [2, "Storm", 7]
```

6. Индекс массива имеет тип `num`. Результат доступа имеет тип элемента.
7. Выход за границы массива — ошибка времени выполнения.
8. Индексация начинается с нуля.
9. Блок `{ ... }` создаёт область видимости. Переменная доступна от объявления до конца блока и во вложенных блоках.
10. Во вложенной области допускается затенение имени внешней области.
11. Переменная цикла `for` создаётся автоматически, имеет тип `num`, существует только в теле цикла. Явное присваивание ей внутри тела запрещено.

## 3. Управляющие конструкции

1. Условие `if` имеет тип `flag`.

Корректно:

```z
if age >= 3 {
    out(age)
}
```

Ошибка:

```z
if age {
    out(age)
}
```

2. Если условие истинно, выполняется блок `if`, иначе при наличии — блок `else`.
3. Условие `loop` имеет тип `flag`.
4. Перед каждой итерацией `loop` условие вычисляется заново. При `no` цикл завершается.
5. В `for` выражения после `from` и `to` имеют тип `num`.

Корректно:

```z
for i from 1 to 5 {
    out(i)
}
```

Ошибка:

```z
for i from 1.0 to 5.0 {
    out(i)
}
```

6. Верхняя граница `to` включается.
7. Если начальное значение больше конечного, тело не выполняется; это не ошибка.
8. Явное изменение переменной цикла `for` запрещено.

Ошибка:

```z
for i from 1 to 5 {
    i = i + 1
}
```

9. Вложенность управляющих конструкций не ограничена.

## 4. Функции

1. Имя функции уникально в программе. Перегрузка не поддерживается.
2. Параметры — локальные переменные тела функции. Имена параметров одной функции уникальны.
3. Параметр нельзя повторно объявить в той же области; во вложенном блоке затенение допускается.
4. Функция объявляется до использования. Рекурсия разрешена.
5. Число и типы аргументов совпадают с параметрами.

Корректно:

```z
fun sum(a: num, b: num): num {
    return a + b
}

result := sum(5, 10)
```

Ошибка:

```z
result := sum(5)
```

6. Тип результата вызова совпадает с объявленным возвращаемым типом.
7. `return` допускается только внутри функции.
8. Тип выражения после `return` совпадает с возвращаемым типом. Для функции без типа результата `return` пишется без выражения.
9. Каждая ветвь функции с возвращаемым типом завершается `return`.

Ошибка:

```z
fun test(value: num): num {
    if value > 0 {
        return value
    }
}
```

Корректно:

```z
fun test(value: num): num {
    if value > 0 {
        return value
    } else {
        return 0
    }
}
```

10. Программа содержит ровно одну функцию `entry` без параметров. Глобальные переменные не поддерживаются.

## 5. Ввод и вывод

1. `in<Тип>()` читает одно значение простого типа: `num`, `real`, `text`, `flag`.
2. Тип результата совпадает с указанным типом.

```z
age := in<num>()
name := in<text>()
```

3. Для `num` вводится целое число, в том числе отрицательное.
4. Для `real` вводится вещественное число с десятичной точкой.
5. Для `text` вводится строка.
6. Для `flag` допустимы только `yes` и `no`.
7. `out(выражение)` выводит значение простого типа.
8. Вывод массива целиком через `out` запрещён; элементы выводятся по индексу.

Корректно:

```z
ages: []num = [2, 4, 7]
out(ages[0])
```

Ошибка:

```z
out(ages)
```

## 6. Дополнительные правила

1. `num` — знаковое 32-битное целое: от `-2147483648` до `2147483647`.
2. `real` — 64-битное вещественное число двойной точности.
3. Деление `num` — целочисленное с отбрасыванием дробной части к нулю.
4. Деление или остаток от деления `num` на ноль — ошибка времени выполнения.
5. Деление `real` на `0.0` — ошибка времени выполнения.
6. Операнды и аргументы вычисляются слева направо.
7. `&&` и `||` используют сокращённое вычисление.
8. Массивы имеют ссылочную семантику при присваивании и передаче в функцию.
9. `==` и `!=` для `text` сравнивают содержимое.
10. Выражения `from` и `to` в цикле `for` вычисляются один раз до начала цикла.
11. После каждой итерации `for` переменная цикла увеличивается на `1`.
12. Явное преобразование выполняется вызовом вида `real(x)`, `num(x)` только между допустимыми парами числовых типов; набор преобразований фиксируется реализацией.
13. Переполнение `num` обрабатывается по правилам 32-битной знаковой арифметики.
14. Любая операция или комбинация типов вне правил спецификации — семантическая ошибка.
15. При лексической, синтаксической или семантической ошибке трансляция завершается сообщением об ошибке.

---

## 7. Общие правила программы

1. Выполнение начинается с первого оператора `entry`.
2. Объявления переменных допускаются только внутри функций и блоков.
3. Ключевые слова не используются как идентификаторы.
4. Имена `age`, `Age` и `AGE` различны.
5. Конструкция, допустимая грамматикой, но нарушающая контекстные правила типов, отклоняется семантическим анализом.
