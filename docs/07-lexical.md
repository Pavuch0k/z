# Лексический анализ языка Z

## 1. Назначение

Лексический анализатор читает исходный текст UTF-8 и формирует поток лексем для синтаксического анализатора.

Пробелы, табуляция, переводы строк и комментарии в AST не входят.

## 2. Классы лексем

| Класс | Примеры |
| ----- | ------- |
| Идентификатор | `x`, `sum`, `entry` |
| Ключевое слово | `fun`, `if`, `loop`, `for`, `return` |
| Целый литерал | `0`, `42` |
| Вещественный литерал | `3.14`, `0.5` |
| Строковый литерал | `"hello"` |
| Логический литерал | `yes`, `no` |
| Оператор | `+`, `-`, `*`, `/`, `%`, `==`, `:=` |
| Разделитель | `(`, `)`, `{`, `}`, `[`, `]`, `,`, `:`, `<`, `>` |

## 3. Правила

1. Идентификатор: буква или `_`, далее буквы, цифры или `_`.
2. Ключевое слово не может быть идентификатором.
3. При нескольких возможных лексемах выбирается самая длинная (`==`, `!=`, `<=`, `>=`, `&&`, `||`, `:=`).
4. Комментарий: от `//` до конца строки, только вне строкового литерала.
5. В строке допускаются escape-последовательности: `\\`, `\"`, `\n`, `\t`, `\r`.
6. Незакрытая строка или неизвестный символ — лексическая ошибка с указанием позиции.

## 4. Взаимодействие с другими блоками

Лексер передаёт синтаксическому анализатору только корректный поток лексем. При ошибке трансляция останавливается до построения AST.
