# Типы Z

## 1. Общая модель

Z использует статическую строгую типизацию.

Тип значения известен во время компиляции.

Операции между несовместимыми типами запрещены, если для них не определено
отдельное правило языка.

Z не выполняет неявные преобразования типов.

Основные типы должны быть небольшими по количеству и однозначными по смыслу.

## 2. Базовые типы

Z имеет следующие базовые типы:

```text
bool
int
float
string
```

### 2.1. `bool`

Логическое значение:

```z
active: bool = true
disabled: bool = false
```

Допустимые значения:

```text
true
false
```

`bool` не является числовым типом.

Следующее недопустимо:

```z
x: int = true
```

## 3. `int`

`int` представляет целое знаковое число.

```z
count: int = 10
negative: int = -10
```

Размер `int` определяется реализацией компилятора и не должен зависеть от
исходного кода программы.

Для первой реализации Z целевой платформой является Linux.

Отдельные целочисленные типы (`uint`, `int8`, `int32`, `int64` и другие)
не входят в базовый язык Z.

Они могут быть добавлены позднее при наличии практической необходимости.

## 4. `float`

`float` представляет число с плавающей точкой.

```z
price: float = 10.5
ratio: float = 0.25
```

`int` и `float` являются разными типами.

Неявное преобразование запрещено:

```z
x: int = 10
y: float = x
```

Для преобразования должен использоваться явный синтаксис языка.

Точный формат чисел с плавающей точкой определяется реализацией компилятора
и должен быть одинаково определён для каждой целевой платформы.

## 5. `string`

`string` представляет последовательность байтов в кодировке UTF-8.

```z
name: string = "Nikita"
message: string = "Hello"
```

Строковые литералы используют двойные кавычки.

Строка не является массивом `byte`.

Операции над строками определяются стандартной библиотекой.

## 6. Коллекции

Z использует два основных встроенных типа коллекций:

```text
[]T
map[K]V
```

### 6.1. Последовательность `[]T`

`[]T` представляет динамическую последовательность значений типа `T`.

```z
numbers: []int = [1, 2, 3]
names: []string = ["Ann", "Bob"]
```

Все элементы имеют один тип.

```z
numbers[0]
```

Индекс последовательности имеет тип `int`.

Индекс должен находиться в допустимых границах во время выполнения.

### 6.2. Map `map[K]V`

`map[K]V` представляет отображение ключей типа `K` в значения типа `V`.

```z
ages: map[string]int = {
    "Ann": 20
    "Bob": 25
}
```

Тип ключа и тип значения всегда указываются явно.

Ключ должен быть допустимым типом для map.

Точный набор допустимых типов ключей будет определён реализацией типов.

## 7. Фиксированные массивы

Фиксированный массив имеет тип:

```text
[N]T
```

где `N` — количество элементов, а `T` — тип элемента.

```z
numbers: [3]int = [1, 2, 3]
```

Размер является частью типа.

Следующие типы различаются:

```text
[3]int
[4]int
```

Фиксированный массив и динамическая последовательность `[]T` являются
разными типами.

## 8. Типы структур

Пользовательские типы создаются с помощью `struct`.

```z
struct User {
    name: string
    age: int
}
```

После объявления `User` становится отдельным типом.

```z
user: User
```

Поля структуры имеют собственные типы.

## 9. Типы функций

Функция также имеет тип.

Формат:

```text
fn(T1, T2): R
```

Например:

```z
fn add(a: int, b: int): int {
    return a + b
}
```

Тип функции:

```text
fn(int, int): int
```

Типы аргументов и возвращаемого значения входят в тип функции.

## 10. Вывод типа

Если тип переменной можно определить из значения при объявлении, используется
сокращённая форма:

```z
x := 10
name := "Nikita"
active := true
```

Она эквивалентна:

```z
x: int = 10
name: string = "Nikita"
active: bool = true
```

`:=` разрешён только при объявлении переменной с инициализацией.

Явный тип используется, когда он необходим:

```z
x: int = get_number()
user: User = get_user()
```

## 11. Совместимость типов

Типы должны совпадать с ожидаемыми типами операции.

Например:

```z
x: int = 10
y: int = 20
z: int = x + y
```

Допустимо.

Следующее запрещено:

```z
x: int = 10
y: float = 20.0
z := x + y
```

Компилятор должен сообщить об ошибке типов.

## 12. Явные преобразования

Z не выполняет неявные преобразования.

Преобразование выполняется явно:

```z
x: int = 10
y: float = float(x)
```

Набор допустимых преобразований определяется системой типов.

Преобразование не должно происходить автоматически только потому, что
целевой тип может содержать исходное значение.

## 13. `null` и отсутствие значения

В базовой версии Z отсутствует универсальное значение `null` или `nil`.

Типы не могут неявно содержать отсутствие значения.

Механизм представления необязательных значений будет определён отдельно,
если он потребуется языку.

## 14. Указатели и ссылки

Указатели и ссылки не входят в минимальную систему типов первой версии Z.

Они могут быть добавлены позднее, если потребуются для производительности,
низкоуровневого программирования или взаимодействия с системными API.

## 15. Принципы системы типов

Система типов Z должна следовать следующим правилам:

- типы проверяются во время компиляции;
- неявные преобразования запрещены;
- одинаковые операции имеют одинаковые правила для всех типов;
- тип должен иметь однозначный смысл;
- количество встроенных типов должно оставаться минимальным;
- специальные типы добавляются только при наличии практической необходимости;
- ошибки типов должны обнаруживаться до запуска программы;
- типовая информация должна быть удобна для анализа человеком и ИИ.
