# Объявления Z

## 1. Общая модель

Объявление связывает имя с сущностью языка.

Z использует единый принцип:

```text
name: type = value
```

Если тип можно однозначно определить из значения, используется сокращённая форма:

```text
name := value
```

Объявление должно быть однозначным для компилятора и удобным для анализа ИИ.

## 2. Объявление переменной

Переменная с явным типом:

```z
x: int = 10
name: string = "Nikita"
active: bool = true
```

Переменная с выводом типа:

```z
x := 10
name := "Nikita"
active := true
```

Тип переменной определяется во время компиляции.

## 3. `:=`

`:=` используется для объявления переменной с инициализацией и выводом типа.

```z
x := 10
```

Эквивалентная форма:

```z
x: int = 10
```

`:=` нельзя использовать для обычного присваивания.

Неверно:

```z
x := 10
x := 20
```

Если переменная уже существует, используется `=`:

```z
x := 10
x = 20
```

## 4. Явный тип

Явный тип указывается после имени:

```z
x: int = 10
user: User = get_user()
numbers: []int = [1, 2, 3]
```

Явный тип обязателен, когда его невозможно или нежелательно выводить из
инициализатора.

Например:

```z
x: int
```

объявляет переменную без начального значения.

## 5. Инициализация

Переменная может быть объявлена с начальным значением:

```z
x: int = 10
```

или без него:

```z
x: int
```

Переменная с `:=` всегда должна иметь инициализатор:

```z
x := 10
```

Следующее недопустимо:

```z
x :=
```

## 6. Присваивание

`=` изменяет значение уже объявленной переменной.

```z
x := 10
x = 20
```

Тип нового значения должен соответствовать типу переменной.

```z
x: int = 10
x = 20
```

Следующее запрещено:

```z
x: int = 10
x = "text"
```

Неявное изменение типа переменной не допускается.

## 7. Множественные объявления

В базовой версии Z каждое имя объявляется отдельно.

Не используются формы:

```text
a, b := 1, 2
```

или:

```text
a: int, b: int = 1, 2
```

Отдельные объявления делают структуру исходного кода проще для анализа.

```z
a := 1
b := 2
```

## 8. Повторное объявление

В одной области видимости имя не может быть объявлено повторно.

Недопустимо:

```z
x := 10
x := 20
```

Для изменения значения используется присваивание:

```z
x := 10
x = 20
```

Во вложенной области видимости имя может быть объявлено заново, если правила
областей видимости допускают затенение.

## 9. Области видимости

Область видимости локального объявления начинается после его объявления.

```z
fn main() {
    x := 10
    print(x)
}
```

`x` доступен только в своей области видимости и её вложенных областях.

```z
fn main() {
    x := 10

    if x > 0 {
        y := 20
        print(x)
        print(y)
    }

    print(x)
}
```

`y` недоступен за пределами блока `if`.

## 10. Порядок объявлений

Объявление должно находиться до первого использования имени.

Недопустимо:

```z
print(x)
x := 10
```

Допустимо:

```z
x := 10
print(x)
```

Это правило делает разрешение имён линейным и предсказуемым.

## 11. Объявления в блоках

Объявления разрешены внутри блоков:

```z
if condition {
    x := 10
    print(x)
}
```

Область видимости определяется структурой блоков языка.

## 12. Глобальные объявления

Глобальные переменные могут быть объявлены на уровне модуля:

```z
version: string = "0.1"
```

Локальные и глобальные объявления используют одинаковую форму.

Правила допустимых инициализаторов глобальных переменных определяются
правилами компиляции и выполнения модуля.

## 13. Константы

В базовой версии Z отдельного синтаксиса `const` нет.

Если значение не должно изменяться, это пока является соглашением уровня
программы.

Механизм констант может быть добавлен позднее, если он потребуется для
компиляции, оптимизации или выражения намерения программиста.

## 14. Объявления структур

Структура объявляется отдельно от переменных:

```z
struct User {
    name: string
    age: int
}
```

После объявления структуры её имя становится типом:

```z
user: User = User {
    name: "Nikita"
    age: 25
}
```

## 15. Объявления функций

Функция объявляется с помощью `fn`:

```z
fn add(a: int, b: int): int {
    return a + b
}
```

Параметры функции всегда имеют явные типы.

Тип возвращаемого значения указывается после `:`.

Функция без возвращаемого значения не указывает тип результата:

```z
fn print_number(x: int) {
    print(x)
}
```

## 16. Имена

Имя объявления должно быть идентификатором, определённым в лексической
спецификации Z.

Имена чувствительны к регистру.

Например:

```z
value := 10
Value := 20
```

`value` и `Value` являются разными именами.

## 17. Ключевые слова

Ключевые слова языка нельзя использовать в качестве имён.

Например, если `fn` является ключевым словом:

```z
fn := 10
```

недопустимо.

## 18. Основные правила

Система объявлений Z следует простому набору правил:

- `name: type = value` — явное объявление;
- `name := value` — объявление с выводом типа;
- `=` — присваивание существующей переменной;
- `:=` — только новое объявление с инициализацией;
- каждое имя объявляется отдельно;
- повторное объявление в одной области видимости запрещено;
- использование имени до объявления запрещено;
- тип переменной не изменяется после объявления;
- параметры функций имеют явные типы;
- неявных преобразований типов нет.

Цель этих правил — минимальное количество вариантов синтаксиса и
предсказуемое разрешение объявлений.
