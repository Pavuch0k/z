# Назначение Z

Z — учебный язык программирования, ориентированный на разработку программ
с помощью искусственного интеллекта.

Основная цель Z — создать компактный, строго типизированный и предсказуемый
язык, который удобно генерировать и анализировать с помощью ИИ.

## Цели

- Экономное использование токенов.
- Строгая типизация.
- Явные импорты.
- Минимальный синтаксис.
- Отсутствие синтаксического сахара.
- Предсказуемая структура кода.
- Простота анализа и генерации кода ИИ.
- Понятные ошибки компилятора.
- Высокая производительность.
